# Georgia Film Society Website

Static HTML website for Georgia Film Society.

## Current build approach

- Static HTML
- Tailwind CDN
- No npm
- No build command
- Deployed through Vercel previews from the `institutional-site` branch

## Canon

Georgia Film Society is the umbrella institution.
Cardennes Film Festival is the flagship festival brand.
The site should remain restrained, cinematic, editorial, institutionally credible, and future-facing.

## Production safety

Production is protected on the `main` branch.
New institutional work is developed on `institutional-site`.
